
# Hyphal Space

**Life, beyond Earth.**

[Hyphal Space](https://hyphalspace.com) is a fungal biotechnology research initiative exploring biological systems for space exploration, sustainable habitats, and closed-loop resource management. Built on the cultivation and genetics foundation of [Hyphal Farms](https://hyphalfarms.com), the project investigates how fungi and mycelium can support life in extreme environments and enable practical applications on Earth.

## Features

- Responsive, single-page research and development website
- Four research directions spanning biofabricated materials, circular resource systems, regenerative cultivation, and extreme-environment biology
- Development framework connecting fungal genetics, experimentation, and applied technologies
- Scientific imagery, custom branding, and space-inspired visual design
- Formspark inquiry form for research partnerships, technical collaborations, and funding opportunities
- Links to the broader Hyphal ecosystem
- Search engine optimization, social metadata, and Google Analytics integration

## Built With

- HTML, CSS, and JavaScript
- Bootstrap and Bootstrap Icons
- BootstrapMade Stratify template and existing vendor assets
- Formspark for inquiries
- Google Analytics 4

## Project Files

- `index.html` - Page content, research areas, navigation, and inquiry form
- `assets/css/main.css` - Custom styling, visual effects, and responsive layouts
- `assets/js/main.js` - Site interactions and navigation behavior
- `assets/img/` - Brand assets, scientific imagery, and concept artwork
